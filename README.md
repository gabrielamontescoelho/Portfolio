# Portfólio React

Projeto desenvolvido como atividade prática utilizando React e Vite, com o objetivo de apresentar informações profissionais de forma organizada e responsiva.

## Tecnologias Utilizadas

* React
* Vite
* JavaScript
* HTML5
* CSS3

## Funcionalidades

* Apresentação pessoal
* Seção "Sobre Mim"
* Contato com links para GitHub e LinkedIn
* Exibição dinâmica de telefone utilizando useState
* Listagem de experiências utilizando componentes reutilizáveis
* Listagem de habilidades utilizando renderização com map()
* Interface estilizada com CSS personalizado

## Conceitos React Aplicados

* Componentização
* Props
* useState
* Renderização de listas com map()
* Organização de projeto em componentes reutilizáveis

## Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/gabrielamontescoelho/Portfolio.git
```

Acesse a pasta do projeto:

```bash
cd Portfolio
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
